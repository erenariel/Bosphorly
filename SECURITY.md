# Security policy

This is a **frontend prototype**, not a commercial reservation or payment system. Do not enter real passenger, health, passport or credit card details. The public sample dashboard contains invented data and must not be used as an administrative portal.

## Disclosure
Report vulnerabilities through the GitHub repository's private vulnerability reporting feature after it is enabled, or through a private channel confirmed by the project owner. Do not post exploit details, tokens or real personal data in public issues.

## Credentials
Never commit API keys, payment secrets, hotel guest lists or raw supplier contracts. Set up GitHub Actions secrets and production environment separation before any integrations are introduced.
