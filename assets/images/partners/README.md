# Partner tour photos

Photos on the tour comparison cards (`prices.html`) come from each tour company's own website and are used
with the company's permission (Blue Brothers, Orient Bosphorus, Sea & Land, Azure Tour, Alaturka Hamam).
Each card names the company as the photo source. Images were cropped to 16:10 and saved as WebP
(600 px and 900 px); no other changes. Each photo is used only on that company's own tours.
