# Contributing

The code is publicly shareable for feedback, but there is no open-source reuse license yet. Open an issue to propose changes before submitting a large patch.

## Rules
- Do not introduce unverified agency partnerships, rates, booking availability, service guarantees or user reviews.
- Do not copy third-party copyrighted brochure photos or official rail map imagery into the repo without permission.
- Keep user data and supplier contracts out of commits.
- Keep transport claims linked to official, dated sources.
- Validate mobile layout, keyboard accessibility, JS syntax and static page links.
- Do not alter the separate KonaklamaFlow repository.
