# Bosphorly organic search strategy

Bosphorly intends to be a genuinely useful Istanbul travel information source that also clearly identifies optional booking/intermediation offers.

## Principles

- Publish original, verified English and Turkish content before scaling translations.
- Every guide should answer a traveler question directly, identify its author/editor and review date, and link to official sources.
- Use semantic HTML, descriptive titles, hreflang on verified translations, accessible maps plus textual alternatives, and JSON-LD only where it accurately describes visible content.
- Make pages crawlable without requiring scripts, login, or payment.
- Avoid doorway pages, keyword stuffing, invented reviews, fake availability, scraped itinerary text, misleading price claims or purported agency endorsements.
- Evaluate Google Search Console performance, canonical URLs, mobile Core Web Vitals and structured-data validity after actual public deployment.

**No search platform or AI-answer inclusion is guaranteed.** Content must help the traveler first.

## Suggested topical guides

Airport transfers; arrival at IST vs SAW; M11/M4 connections; Sultanahmet access; Bosphorus transport; Byzantine and Ottoman heritage; public transport card; ferry basics; accessibility; cancellation policies; neighborhoods on both shores.
